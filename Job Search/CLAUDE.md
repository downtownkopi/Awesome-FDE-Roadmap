# Job Search — Protocol

Operational tracking for actually landing in front of an interviewer —
distinct from `Test FDE Role/` (interview-skill practice). No quiz
loop here; update these files as real-world events happen (an
application sent, a referral conversation, a resume revision).

Files:
- `resume-notes.md` — which real experience/stories to surface for
  each target company, keyword alignment, open gaps.
- `applications-tracker.md` — one row per application: company, role,
  status, referral, dates, next action.
- `networking.md` — target contacts, referral asks, follow-ups.

## When to update

- After sending an application → add a row to `applications-tracker.md`.
- After any change in application status (screen scheduled, rejected,
  offer, etc.) → update that row.
- After a networking conversation or a referral ask → add/update a row
  in `networking.md`.
- After revising the resume for a specific company → update
  `resume-notes.md`'s per-company section.
- If a `Test FDE Role/behavioral/star-stories.md` story gets
  sharpened/added, check whether `resume-notes.md`'s evidence list for
  the relevant company should cite it too.

## After updating

Refresh the Job Search row in root `PROGRESS.md`, e.g. "3 applications
sent (OpenAI, Anthropic, Cohere), 1 referral secured."
