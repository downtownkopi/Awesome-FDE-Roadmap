# How to use this file

1. Pick a prompt below with an empty S/T/A/R.
2. Draft a real story from your own work history — specific names
   (role/company can stay anonymized), specific numbers, specific
   outcome.
3. Fill in the template. Keep it tight enough to say out loud in
   60-90 seconds.
4. When quizzed on Category 5 (Behavioral) in a `Test FDE Role`
   session, these are the stories to pull from and adapt live — not to
   recite verbatim (interviewers can tell).
5. Revisit and sharpen after every mock session that touches this
   prompt — add a "Sharpened after" line noting what the model answer
   in `knowledge-tracker.md` caught that this draft missed.
